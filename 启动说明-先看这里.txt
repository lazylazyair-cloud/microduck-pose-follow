小黄鸭姿势跟随版 - Windows 启动说明

1. 请在本文件所在的项目根目录确认能看到 package.json、src、public。
2. 双击 start-microduck.bat。
3. 第一次启动会安装依赖，需要联网并等待完成。
4. 看到 VITE 的 Local 地址后，在电脑浏览器打开该地址。
5. 使用姿势跟随时，点击页面里的“姿势跟随”并允许摄像头权限。

请保持黑色命令窗口开启。关闭窗口会停止网页服务。

摄像头说明：
- 本机电脑请使用 http://localhost:端口 或 http://127.0.0.1:端口。
- 手机访问电脑的局域网 IP 时，普通 HTTP 通常不能调用摄像头；
  手机端请使用 HTTPS 部署地址。
- 如果浏览器不支持 Web Crypto，程序会跳过本地资源哈希校验，
  不会因此阻止本地仿真启动；支持 Web Crypto 时仍会进行 SHA-256 校验。
